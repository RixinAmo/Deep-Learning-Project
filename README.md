# CNN-Project: Brain Tumor Classification

This project uses a Convolutional Neural Network (CNN) to classify brain MRI images into four classes: glioma, meningioma, pituitary tumor, and no tumor.



## Dataset

The dataset used for this project is too large to upload to GitHub.  
You can download it from Google Drive:

[Download Dataset](https://drive.google.com/drive/folders/15TdIs5CM2-C4VDgcCCWJUcFd1gBR-qjw?usp=sharing)

> After downloading, unzip it and place it in `CNN-Project/dataset/` folder to run the code.

## How to Run

1. Install dependencies:  
```bash
pip install -r requirements.txt
Open deep_learning_project.ipynb in Google Colab or Jupyter Notebook.
Make sure the dataset/ folder is in the project directory with proper class subfolders (glioma, meningioma, pituitary, no_tumor).
Run the notebook cells step by step.
```
